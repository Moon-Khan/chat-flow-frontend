# Chat Flow Frontend

React + Vite frontend for the Chat Flow app (authentication, chat, stories, and real-time updates via Socket.IO).

## 🌐 Live App

👉 https://chat-flow-frontend-self.vercel.app/

## Tech Stack

- React 19
- Vite
- React Router
- Axios
- Socket.IO Client
- Styled Components
- Framer Motion

## Prerequisites

- Node.js 18+ (recommended)
- npm
- Running backend server
